# Экспорт APK

Android-приложение показывает установленные приложения и сохраняет их APK в папку, выбранную через системный выбор файлов. Для приложения с разделёнными APK сохраняются базовый и все дополнительные APK; для установки такого приложения все части необходимо установить вместе, например с помощью `adb install-multiple`.

Откройте проект в Android Studio, установите Android SDK 35 и соберите **Build → Build APK(s)**. Нужны JDK 17 и Gradle 8.9 или совместимая версия. Результат — `app/build/outputs/apk/debug/app-debug.apk`.

Установите APK на телефон, откройте приложение, выберите приложение из списка и укажите или создайте папку в системном диалоге. Android не позволяет приложению автоматически размещать произвольные файлы на домашнем экране; откройте папку через файловый менеджер или создайте её ярлык средствами вашего телефона.
